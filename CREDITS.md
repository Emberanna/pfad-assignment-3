# Credits and licenses

## Visual reference

[Penderecki's Garden](https://pendereckisgarden.pl/en/studio_more) inspired the point-cloud aesthetic. No code, scanned point clouds, music, or website screenshots from that project are included in the runtime.

Landscape photographs supplied during design discussions informed composition. Those photographs are not bundled in this delivery.

## Tree model

[Island Tree 02 — Poly Haven](https://polyhaven.com/a/island_tree_02), distributed under [CC0](https://polyhaven.com/license). The included 1K glTF model and its PBR textures are sampled into colored points. Geometry buffers are repartitioned into smaller files for static-host file-size limits without changing topology.

The model-specific source record is included in `dist/assets/nature/island_tree_02/LICENSE-SOURCE.md`.

## Rendering library

[Three.js r170 / 0.170.0](https://github.com/mrdoob/three.js/tree/r170), including GLTFLoader and BufferGeometryUtils. MIT license; see `THIRD_PARTY_NOTICES.md`.

## Audio

The 48-second Meadow Study is an original synthesized note sequence generated by `tools/create-demo.mjs`. It does not reproduce an external recording or composition. User-selected media remains local and is not part of the repository.

## Fonts

The interface uses installed system fonts. No external font service or font files are required.

## Tool use

Codex was used for development and revision as described in `PROCESS.md`. Browser audio implementation was informed by [MDN's AnalyserNode documentation](https://developer.mozilla.org/en-US/docs/Web/API/AnalyserNode).
